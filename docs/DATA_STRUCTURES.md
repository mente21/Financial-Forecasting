# Data Structures & Architecture

This document describes the core data structures, classes, and file formats used in the Financial Forecasting System.

---

## 1. Domain Entities & Structs

Defined in `src/data/stockdata.h`:

### `StockRecord`
Represents a single row of market trading data parsed from CSV sources.

```cpp
struct StockRecord {
    std::string date;     // Date format string (e.g. "YYYY-MM-DD")
    double openPrice;     // Opening price for trading session
    double highPrice;     // Daily highest recorded trade price
    double lowPrice;      // Daily lowest recorded trade price
    double closePrice;    // Session closing price (primary feature used in forecasting)
    long long volume;     // Total traded share volume

    StockRecord();
    StockRecord(const std::string& d, double o, double h, double l, double c, long long v);
};
```

### `ForecastResult`
Encapsulates both future-looking and out-of-sample backtesting prediction outputs.

```cpp
struct ForecastResult {
    std::vector<std::string> dates;              // Projected or evaluated date labels
    std::vector<double> actualPrices;             // Ground truth prices (populated during backtesting)
    std::vector<double> predictedPrices;          // Output projections generated by the model
    double dtwDistance;                           // Dynamic Warping distance of best-matched historical regime
    int matchedHistoricalStartIndex;              // Start index of closest historical regime in price vector
    int matchedHistoricalEndIndex;                // End index of closest historical regime in price vector

    ForecastResult();
};
```

### `EvaluationMetrics`
Defined in `src/evaluation/evaluation.h`:

```cpp
struct EvaluationMetrics {
    int sampleCount;              // Number of evaluated time periods (N)
    double mae;                   // Mean Absolute Error ($)
    double mape;                  // Mean Absolute Percentage Error (%)
    double mse;                   // Mean Squared Error ($^2)
    double rmse;                  // Root Mean Squared Error ($)
    double directionalAccuracy;   // Directional accuracy percentage (0.0% to 100.0%)

    EvaluationMetrics();
};
```

## 2. Core Engine Classes

### `DataReader` (`src/data/datareader.h`)
Handles CSV file ingestion, header identification, token trimming, and type conversion.
- `std::vector<StockRecord> readCSV(const std::string& filepath)`: Parses files with quote handling and tolerant header mapping (`date`, `open`, `high`, `low`, `close`, `volume`).
- `static std::vector<double> extractClosePrices(const std::vector<StockRecord>& records)`: Extracts continuous closing price vector.
- `static std::vector<std::string> extractDates(const std::vector<StockRecord>& records)`: Extracts chronological timestamps.

### `DPForecaster` (`src/algorithm/forecasting.h`)
Implements the core dynamic programming engine:
- `double computeDTW(const std::vector<double>& s1, const std::vector<double>& s2)`: Computes pairwise DTW distance matrix.
- `std::vector<double> zNormalize(const std::vector<double>& seq)`: Normalizes price sequences for scale invariance.
- `ForecastResult forecast(const std::vector<double>& historicalPrices)`: Performs top-K search and projects $H$ forward days.
- `ForecastResult backtest(const std::vector<double>& allPrices, int testSize)`: Splits data into train/test sets to evaluate out-of-sample accuracy.
- `const std::vector<std::vector<double>>& getLastDPTable() const`: Exposes the dynamic programming table for inspection/debugging.

### `Evaluator` (`src/evaluation/evaluation.h`)
Computes out-of-sample statistical performance:
- `static EvaluationMetrics calculateMetrics(const std::vector<double>& actual, const std::vector<double>& predicted, double baselinePrice)`
- `static void printReport(const EvaluationMetrics& metrics, const ForecastResult& result)`

## 3. CSV Dataset Format Specification

The CSV reader supports case-insensitive column headers in any column order:

| Header Name | Type | Required | Description |
|---|---|---|---|
| `Date` | String | Recommended | Timestamp formatted e.g., `YYYY-MM-DD` |
| `Open` | Floating point | Optional | Trading open price |
| `High` | Floating point | Optional | Daily session high |
| `Low` | Floating point | Optional | Daily session low |
| `Close` | Floating point | **Required** | Primary signal used for DTW pattern matching |
| `Volume` | Integer (64-bit) | Optional | Trading volume |

### Minimum Row Constraint
To run both backtesting and forecasting:
$$\text{Total Records} \ge \text{windowSize} + \text{forecastHorizon} + \text{testSize}$$
For default configuration ($M=10, H=5, T=5$), a minimum of **20 rows** is strictly required.
